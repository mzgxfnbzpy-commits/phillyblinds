1 · What changed & why

All four roller-family configurators were standardized to a single, consistent interaction model. The driving rule (Justin, 2026-06-24):

Universal Step 1 rule: Width + Height come first, then Mount immediately below, in the same first setup area. Quantity lives in Step 1 too. Soluna is the visual reference (teal bubble buttons, white cards, right-side summary) — but the old Soluna step order (mount alone on Step 1, dimensions on Step 2) was discarded.

For shades, Step 1 = Width · Height · Inside/Outside Mount · Quantity. Exterior Roller is a shade that mounts like hardware, so its Step 1 uses Wall / Ceiling-Soffit mount instead of inside/outside.

2 · Selection styling — the "teal bubble"

In css/global.css, --gold is defined as #2DE0C1 (teal), so var(--gold) renders teal everywhere. The signature selected-state is the .opt-btn.sel glow ring:

box-shadow: 0 0 0 3px rgba(45,224,193,.15), 0 2px 8px rgba(45,224,193,.2)
